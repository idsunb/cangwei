层次做法适用

书中 §3.8 近似h=Σ qₖ(aₖ…cₖⱼ…)+…，相关进 dₖⱼcₖⱼ快速近似（抛物线页）
max_q H(q) = Σᵢ P(rᵢ) · log( q₀R₀ + Σₖ qₖ(1+rᵢₖ) ) s.t. Σ q = 1, qₖ ≥ 0（或允许卖空/透支） 相关只改变 P(r₁,…,rₙ)： 独立: P = Πₖ pₖ 相关: P 由联合表 / copula 生成 ρ↑ → 同涨同跌变多 → 分散红利↓ → 几何增长↓ ρ↓ → 对冲变强 → 可提高总仓位与 H
风险提示：ρ 由历史估计时应使用区间或情景压力；两两相关 ≠ 完整依赖结构（尾部相关可能更大）。
